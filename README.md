# Perspective
Data and code used to construct figures in the perspective

## Supporting Information (`SI_2026/`)

`SI_2026/` holds the datasets (Datasets S1-S17), the Python scripts and the statistics tables of the Supporting
Information of PNAS manuscript 2026-25352; see `SI_2026/README.md`. The 7 largest dataset files are in the Zenodo record
https://doi.org/10.5281/zenodo.23925266.
